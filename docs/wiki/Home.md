# Synapse documentation

Synapse turns media, GitHub repositories, and research papers into a permanent,
searchable learning library. This documentation covers installation, everyday
workflows, model configuration, storage, and operations.

## Start here

- [Getting Started](https://github.com/Jarzembak/synapse/wiki/Getting-Started) — install Synapse, start the CPU or GPU
  stack, and create a first project.
- [Using Synapse](https://github.com/Jarzembak/synapse/wiki/Using-Synapse) — Projects, Library, Quick-refs, Jobs,
  System, Logs, Settings, and themes.
- [How Synapse Works](https://github.com/Jarzembak/synapse/wiki/How-Synapse-Works) — services, pipelines,
  dependencies, citations, and staleness.
